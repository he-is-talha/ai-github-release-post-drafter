## LinkedIn

**Hook:** We’ve refined the end-to-end demo release path, streamlining the workflow from GitHub webhook to draft generation.

This release focuses on improving the delivery of drafts following a GitHub webhook event. Specifically, we've implemented idempotent handling for retry attempts, ensuring consistent behavior regardless of network conditions or concurrent requests. The updated process now includes a detailed walkthrough: GitHub webhook triggers an HMAC verification, which then claims the relevant data, assigns a tier, feeds it to an LLM for draft creation, and finally submits an approval PR. We’ve also established schema-locked drafts that will never auto-publish, enhancing reliability. This follows on from v1.0.2, where we initially polished this release path.
